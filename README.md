# 宝宝记录 · Baby log

在 DeepSeek Harness 的 Web 界面里记录宝宝的日常：

- **体重**：每次称重记一条；同一天多次称重时，曲线、今日卡片和每日汇总都取当天平均值。
- **身高**：每次测量记一条（cm），自动连成身高曲线。
- **喂奶**：母乳 ml、奶粉 ml；亲喂按**分钟 + 侧别（左/右/双）**记录，无法量化的亲喂不强行填 ml。
- 首页展示“今日每次奶量”折线，按时间顺序看每一顿的量和当天平均线。
- 亲喂时长不计入奶量图，但会出现在「上次喂奶」、今日卡片、时间线、历史、Excel 和每日汇总里。
- **尿布**：小便、大便次数。
- **补充剂**：维生素 D3、益生菌的服用时间与剂量。

侧栏底部、设置按钮旁的**奶瓶图标**打开面板，包含四个页签：

| 页签 | 内容 |
| --- | --- |
| 今日 | 快捷记录表单（含身高、亲喂分钟/侧别）、今日奶量/喂养/尿布/体重/身高卡片、**今日每次奶量折线**、今日时间线 |
| 趋势 | 体重曲线、身高曲线、每日奶量（母乳+奶粉堆叠）、**每次奶量折线**（可切换日期）、每日大小便、喂养时段分布、近 7 天补充剂打卡 |
| 记录 | 最近 30 天按天分组的历史，可修改或删除 |
| 设置 | 宝宝昵称与出生日期、数据文件位置、**Excel 导出**、JSON 导出/导入 |

## 数据在哪里

记录由 Host 半写入本机 DSH 数据目录：

```
~/.dsh/baby-diary/data.json
```

（若设置了 `DSH_HOME`，则是 `$DSH_HOME/baby-diary/data.json`。）

因此刷新页面、清空站点存储、更换浏览器访问端口都不会丢失记录。写入采用
临时文件 + 原子改名；文件损坏时会先改名为 `data.json.corrupt-<时间戳>`
保留现场，再从空状态开始。

## 安装

```text
Plugins → Add plugin → 选择本目录（本地目录安装）
```

安装后**完全退出并重新打开 DSH**，让 Host 半与浏览器端都加载最新代码；侧栏底部
（设置按钮旁）出现奶瓶图标即可使用。

## 版本与更新

当前版本 **1.1.0**，可在插件「设置 → 关于」底部看到版本号。

为什么其他位置“检测不到更新”：

- 从 GitHub 安装时，profile 的 `package.json` 会写成 `github:lklkqiwt/baby-care`，pnpm 会把它**锁定到安装时的那个 commit**；DSH 启动时不会去 GitHub 拉新提交，也没有“检查更新”这一动作。
- 插件没有发布到 npm，Plugin Manager 无法像 npm 包那样比较版本号/自动升级。
- 如果 `package.json` 的 `version` 一直不变，即使重新安装，版本看起来也还是旧的。
- Host 半的模块在进程内只加载一次，更新后必须**完全重启 DSH**，只刷新页面不够。

更新其他安装的步骤：

1. 本项目里把 `package.json` 的 `version` 递增（本次已到 `1.1.0`），提交并打 tag：
   ```bash
   git tag v1.1.0
   git push
   git push origin v1.1.0
   ```
2. 在另一处 DSH 的 **Plugins** 里移除旧的 Baby log。
3. 重新安装：`github:lklkqiwt/baby-care`，或锁定 tag 的 `github:lklkqiwt/baby-care#v1.1.0`。
4. **Cmd+Q 完全退出并重开 DSH**，到「设置 → 关于」确认版本号。

如果多台机器共用同一个 iCloud 目录，更简单的方式是从该**本地目录**安装（profile 里会写成 `link:/...`）；之后改文件刷新页面即可，Host 半改动再重启一次。

数据通道是 Connection 的精确 Fetch 路由 `/api/baby-diary`（`ctx.connection.fetch.register`
注册），`/api` 前缀的挂载与浏览器鉴权由 Connection 负责，只有已认证的浏览器所有者
可以访问；浏览器端与桌面壳都通过 Connection 的传输层发送 `api/baby-diary` 请求。

## 导出

- **导出 Excel（.xlsx）**：包含 6 个工作表——「每日汇总」（从第一天到今天，含奶量、母乳、奶粉、喂奶次数、**亲喂分钟**、大小便、体重、身高、D3/益生菌次数）、「喂奶明细」（含亲喂分钟与侧别）「尿布明细」「体重记录」「身高记录」「补充剂」。带表头样式、冻结首行和筛选。
- **导出 JSON**：完整数据备份，可通过「导入 JSON」恢复；导入会覆盖现有记录。
- Excel 文件在浏览器内直接生成，不依赖任何第三方表格库。

## 限制

- 只在本机 DSH 主机内使用，不做多设备同步；需要备份时用「设置 → 导出 JSON」。
- 记录的是瓶喂的母乳量；亲喂时长没有单独字段，可以写在备注里。
- 图表用 SVG 手绘，不依赖第三方图表库。
